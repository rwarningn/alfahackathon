# Проверка стартовой версии

Проверено локально 21 октября 2026 года:

- `python -m unittest discover -s tests -v`: 4 теста прошли на Python 3.12.14 (доступный локальный runtime). Включают HTTP-сценарии одобрения и отказа, 401/403/409, изоляцию клиентов, запись истории, повторную инициализацию сохранённой БД, валидацию и три рекомендации правил. Docker фиксирует Python 3.12.7; именно эта версия пока не запускалась.
- `node --check web/app.js`: синтаксис JavaScript корректен.
- В браузере вручную пройдено: вход клиента → подача → выход → вход банка → рассмотрение с комментарием → одобрение с комментарием → возврат клиента. Результат, изменившаяся лента и история видны.
- На доступной ширине боковой панели интерфейс переходит в одну колонку; элементы и тексты читаемы.

Docker CLI на машине не найден. Dockerfile и Compose подготовлены, но сборка образа и запуск контейнера **не проверены**. Перед сдачей Егор должен выполнить `docker compose up --build`, пройти основной сценарий, затем перезапустить контейнер и проверить сохранность данных. Публичное развёртывание, нагрузка, полноценный security review и качество кредитного риска не проверялись.

При первом запуске тестов выявлена незакрытая SQLite connection на Windows: context manager теперь явно закрывает соединение после commit/rollback. Повторный запуск тестов прошёл.
